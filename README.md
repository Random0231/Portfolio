# Mohammed Mubashir's Portfolio Website

A modern, responsive portfolio website showcasing my work, skills, and projects. Built with HTML, CSS, and JavaScript.

## Features

- 🎨 Three Theme Modes:
  - Light Mode (Clean & Minimal)
  - Dark Mode (Modern Neon)
  - Glassmorphism (Frosted Glass Effect)
- 📱 Fully Responsive Design
- ✨ Smooth Animations & Transitions
- 📝 Contact Form with Validation
- 🛍️ Project Store Section
- 📧 Newsletter Subscription
- 🔍 Project Showcase with Modal Details

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/yourusername/portfolio.git
```

2. Navigate to the project directory:
```bash
cd portfolio
```

3. Open `index.html` in your browser or use a local server:
```bash
# Using Python
python -m http.server

# Using Node.js
npx serve
```

## Customization

1. Replace `src/images/profile.jpg` with your profile picture
2. Update project information in `src/js/main.js`
3. Modify colors and styles in `src/css/styles.css`
4. Add your own projects to the projects array in `main.js`
